# Mentaiko

Plataforma web universitaria de bienestar emocional.

## Tecnologías

- Frontend: Angular
- Backend: Spring Boot
- Base de datos: PostgreSQL
- Seguridad: Spring Security y JWT

## Estructura

- `frontend`: aplicación Angular
- `backend`: API Spring Boot
- `docs`: documentación del proyecto
